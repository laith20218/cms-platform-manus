# خريطة التنقل الوظيفية — student-web Functional Navigation Diagram

بديل تفاعلي احترافي للصورة الثابتة: نفس المخزون الكامل (37/37 مساراً من `router.tsx` + الأسطح الداخلية والقشرة) لكن قابل للاستكشاف — تصفية، بحث، تفاصيل لكل عقدة وحافة، وتصدير.

## الفتح محلياً (بلا أي خادم)

افتح `index.html` مباشرة في المتصفح (double-click / `file://`):

```
docs/diagrams/student-web-nav-functional/index.html
```

الملف مكتفٍ ذاتياً بالكامل: لا CDN، لا شبكة، لا خطوط خارجية — البيانات محمّلة من `data/graph.js` (نسخة مولّدة آلياً من `data/graph.json` لضمان العمل عبر `file://` حيث `fetch` محجوب). يعمل كذلك من أي خادم ثابت إن وُجد.

## الواجهة

- **بحث**: بالاسم العربي أو المسار أو اسم المكوّن — اختصار `/` يركز حقل البحث.
- **تصفية بالتصنيف**: أسطح رئيسية / من الشريط العلوي / متداخلة / يتيمة / شرطية / **موروثة (أحمر)** / محذوفة / عامة / قشرة.
- **تصفية بنوع الحافة**: قشرة · أساسي · داخلي · حالة URL · حارس/شرط · موروث/ميت · تحديث كامل · رجوع بالتاريخ.
- **أنماط سريعة**: «الأحمر فقط» (كل ما ميت/موروث + أطرافه) و«تبويبات دراستي».
- **نقرة على عقدة**: لوحة تفاصيل (المسار، المكوّن، التصنيف، الحواف الواردة/الصادرة بوصف زنادها — والنقر على حافة يقفز للطرف الآخر). `Esc` يغلقها.
- **تحريك/تقريب**: سحب الخلفية للتحريك، عجلة الفأرة للتقريب، أزرار ＋/－/1:1/⤢.
- **تصدير SVG**: زر «⬇ تصدير SVG» يحفظ المشهد المفلتر الحالي (يعمل حتى عبر `file://`).

## قراءة الأحمر (RED)

الأحمر لا يعمل وحده — كل عنصر أحمر يحمل أيضاً **شارة «ميت/محدوف»** وخطاً متقطعاً:

| ما هو أحمر | لماذا |
|---|---|
| الحزمة `G` (الأسفل): `/`، `/library`، `/practice`، `/my-studies`، `/exam-courses(/:id)` | مسارات تحويلية موروثة — **لا يوجد أي رابط داخلي يشير إليها** (تبقى بقوة قرار المالك 3: تحويلات للروابط القديمة) |
| تحويلات التبويبات المتقاعدة `?tab=exams|leaderboard` | آثار أسطح مهاجرة |
| نمط «رجوع بالتاريخ» (عقدة legacy-back) | **مُنجز (Wave C)** — الصفحات الخمس العميقة تستخدم الآن `useLogicalBack` (سياسة الأب في PathTrail)؛ تُوثَّق كأرشيف |

**أُنجز في Wave C** (لم تعد حمراء في المنتج الحي):
- «العودة للرئيسية» في صفحات القانونيين → أصبحت تشير إلى `/dashboard` مباشرة (لا تحويل مزدوج).
- `<a href>` خام في صفحة التسجيل → أصبحت `<Link>` SPA.
- `/stats` اليتيمة → موضع رسمي: بطاقة «إحصاءاتي» في الملف الشخصي + زوج المسارات مع لوحة المتصدرين.

**ملاحظة دقة تاريخية**: جدول الحواف في `docs/student-web-navigation-recon.md` كُتب قبل مهمة الليلة (Tasks 3/4/8): الجرس صار **لوحة منسدلة** مع «عرض الكل» للصفحة الكاملة، وأُضيف زر «وضع بدون إنترنت» بجانبه، ونافذة «تنويه» قبل التدريب في تفاصيل الحزمة. `graph.json` هنا يعكس الوضع الحالي على main — الجداول المرجعية تبقى المخزون التاريخي الكامل.

## المصدر والحقيقة الوحيدة

`data/graph.json` هو مصدر البيانات: عقد (id, path, component, labelAr/labelEn, class, lane, notes, routerPaths) وحواف (from, to, triggerAr/En, kind, isDeadOrConfusing, unverified). التعديل يكون هنا ثم:

```bash
# 1) regenerate the file:// loader
python3 -c "import json;g=json.load(open('data/graph.json'));open('data/graph.js','w').write('window.__GRAPH_DATA = '+json.dumps(g,ensure_ascii=False,indent=1)+';\n')"

# 2) regenerate the static snapshot (svg + 2x png) — needs node + playwright-core + a chromium
node export.cjs   # resolves playwright-core from ../../../tools/nav-diagram/node_modules
```

## بيان الاكتمال والمنهجية

- المنهجية: مسح ثابت لكل `apps/student-web/src` — `router.tsx` (جدول المسارات الإنتاجي الوحيد) + Navbar/Sidebar/BottomNav/PathTrail/AppShell/ProtectedRoute + كل صفحة تلمس `navigate(`/`<Link`/`<Navigate`/`window.location`/تبديلات تبويب المعامل — مصالَحاً مع main عند `02ac2eaa` (بما فيه تغييرات مهمة الليلة).
- التغطية: **37/37 مسار router** (تحقق آلي: مطابقة كل `path="…"` ضد العقد) + 7 أسطح داخلية (لوحة الإشعارات المنسدلة، وضع بدون إنترنت، تنويه البنك، بانِي التدريب، نافذة خيارات المادة، نمط PathTrail الموحد، نمط الرجوع بالتاريخ) + عقدة القشرة = **53 عقدة، 136 حافة (9 حمراء)** — جرد Wave C بعد التنظيف (رجوع منطقي، قانونيون → /dashboard مباشرة، مراسي SPA في التسجيل، موضع /stats الرسمي في الملف الشخصي). أعيد بناء data/graph.json (كان مستبعداً بقاعدة data/ في .gitignore ولم يُرفع أبداً).
- حواف «تفعيل الكود» الواردة: 12 حافة مفصّلة هنا؛ جرد المهمة الليلية الأصعد يعدّ أكثر عبر مكونات الرفض المشتركة (LockedEmptyState/بطاقات الرفض) — مذكور في ملاحظات العقدة.
- حواف PathTrail الموحدة «الرئيسية»: **حافة نمط واحدة** موثقة، لا نسخة لكل صفحة.
- **غير مُثبَت (UNVERIFIED)** — لا يمكن إثباتها تحليلياً، تُوثَّق كما هي:
  1. قيمة `VITE_OTP_ENABLED` الفعلية لكل بيئة (تؤثر على وجود مسار `/verify-otp`).
  2. حمولات `actionUrl` للإشعارات من الخادم (مقيدة بالقائمة البيضاء في `sanitizeActionUrl.ts`).
  3. هل ما زال سطح خارجي (WebView أندرويد، روابط تسويقية، بريد) يشير إلى المسارات الموروثة الأربعة.

## الملفات

|---|---|
