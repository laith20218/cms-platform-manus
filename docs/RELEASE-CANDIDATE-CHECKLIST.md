# قائمة إطلاق إصدار المرشح — Release Candidate Checklist

> **الغرض:** مصدر واحد مرتّب لاتخاذ قرار «جاهز للإطلاق» على مجموعة الطلاب
> (Pilot). تُعبّأ البنود بالترتيب؛ أي بند غير مكتمل = الإصدار **ليس** جاهزاً.
> مسار بناء حزمة الأندرويد: `docs/android-student-apk-guide.md` (§11)،
> وفحص الجهاز: `docs/RC1-SMOKE-TEST.md`.

## A) تسجيل نسخة الإصدار — Record the release SHA

- [ ] سجّل SHA فرع `main` المراد إطلاقه: `git rev-parse HEAD` = `________`
- [ ] سجّل التاريخ والوقت ورابط الـ PR/الالتزامات المدمجة منذ آخر إصدار
  (آخر ثلاثة إغلاقات ديون: PRs #187/#188/#189؛ إصلاح e2e: PR #190)

## B) صحة الخدمات السحابية — Cloud services healthy

- [ ] **Vercel (student-web)**: الرابط `https://________` يفتح ويظهر تسجيل الدخول
  (بدون أخطاء 5xx)، والنشر يشير إلى نفس SHA الويب أعلاه.
- [ ] **Render (API)**: الرابط `https://________/health` (أو نقطة الفحص المعتمدة)
  يجيب 200، والخدمة ليست في حالة Sleep متعثرة.
- [ ] **Neon (Postgres)**: قاعدة البيانات متصلة من الـ API، لا هجرة معلّقة
  (`dotnet ef database update` محدّثة)، والنسخ الاحتياطي اليومي يعمل.

## C) بيئة الـ API — API environment

- [ ] **JWT/الجلسة**: `Jwt:Key` و`Jwt:RefreshKey` (أو ما يعادلهما) مضبوطة
  كأسرار في Render — قيم قوية، وليست الافتراضيات، وتدويرها موثّق في
  `docs/security/SECRET_ROTATION.md`.
- [ ] **الاستحقاقات (Entitlements)**: مفاتيح توقيع الاستحقاقات ومهلة الانتهاء
  مضبوطة بقيم الإنتاج المعتمدة.
- [ ] **`Features:Offline*`**: افتراضياً **OFF** — لا تُفعَّل إلا إذا كانت حزم
  الأسئلة دون اتصال ستدخل هذا الإصدار فعلاً (قرار المالك). عند التفعيل: اتبع
  خطوات التشغيل المرتّبة في **`docs/OFFLINE-PACKAGES-GO-LIVE.md`** (أعلام Render
  الستة + مفاتيح `Security__Offline__*` الثلاثة + بناء أندرويد بالـSPKI العام) —
  والتصميم الكامل في `docs/offline-program.md` §3.
- [ ] لا أسرار إنتاج في المستودع (البوابة الأمنية في CI خضراء: Security Scan
  + Security Artifact Gate).

## D) حزمة الأندرويد — Android build

- [ ] البناء بروابط الإنتاج عبر `-P`: `STUDENT_WEB_BASE_URL` و`API_BASE_URL`
  (HTTPS فقط — البناء يفشل مبكراً بدونهما).
- [ ] **التوقيع**: مفتاح release خارج المستودع + `apps/android/keystore.properties`
  (محجوب في git؛ القالب `keystore.properties.example`) — والنسخة الموزّعة موقّعة،
  لا `app-release-unsigned.apk`.
- [ ] هوية الحزمة مؤكدة من مخرجات السكربت: `applicationId=com.cms.student`
  مع `versionName`/`versionCode` المطابقين لهذا الإصدار (تحقق `aapt` تلقائي).
  الإصدار الحالي بعد رفع RC2: **versionCode 2 / versionName 0.1.1**.
- [ ] **حزم الأسئلة دون اتصال**: OFF افتراضياً — إن أُريد تفعيلها هنا فاتبع
  `docs/OFFLINE-PACKAGES-GO-LIVE.md` كاملاً (البند C أعلاه + بناء أندرويد
  المفعّل بـ`-POFFLINE_TRUSTED_CLIENT_IMPLEMENTED=true` + سيناريو القبول على
  الجهاز §6 فيه).
- [ ] **التثبيت الإلزامي للشهادات (Pins)**: **اختياري في RC1**، **إلزامي قبل أي
  نشر في Google Play** — `-POFFLINE_API_SPKI_PINS_MANDATORY=true` مع مجموعة
  SPKI حقيقية (سرّ خط الإنتاج، لا يدخل المستودع)؛ الاستخراج والتدوير مع
  فترة تداخل: `docs/security/CERTIFICATE-PINNING.md`.

## E) حالة CI — CI state

- [ ] **Frontend Tests خضراء** بعد إصلاح e2e (PR #190) — علامة `✓` على
  «Run Playwright e2e specs» في آخر تشغيل للفرع المُطلق.
- [ ] ملاحظة الوظائف الحمراء المعروفة (خارج نطاق هذا الإصدار، موثّقة):
  سير عمل **Android Offline Runtime** على `main` يحمل تعطّلين قديمين في
  `OfflineRuntimeInstrumentationTest` (اختبارات Keystore/RSA في المحاكي؛
  أقدم من برنامج الديون — سجل الإغلاق في
  `docs/security/OFFLINE-DEBT-REGISTER.md`). لا تعيق التوزيع الجانبي؛
  تُتتبّع كديون تقنية مستقلة.

## F) اختبارات أجهزة يدوية — Manual device tests

(الفحص المفصّل خطوة بخطوة: `docs/RC1-SMOKE-TEST.md`)

- [ ] **تذكّرني (remember-me)**: دخول مع «تذكّرني» يستأنف بعد إغلاق التطبيق؛
  دخول بدونه يُنهى الجلسة بعد الإغلاق (كلا السلوكين مقصود).
- [ ] **الصفحات القانونية** تفتح (الشروط/الخصوصية) من داخل التطبيق.
- [ ] **التنقل في الدراسة**: لوحة الطالب ← المواد ← الكورس ← الحلقة/الملف
  يعمل بلا طرق مسدودة.
- [ ] **الكاش دون اتصال**: حفظ ملف ثم فتحه في وضع الطيران؛ لوحة «وضع بدون
  إنترنت» تعرض العدّاد؛ محتوى YouTube يظهر ملاحظة «غير قابل للحفظ».
- [ ] **دخول المشرف (admin)** على `admin-web` يعمل بحساب SuperAdmin واحد
  على الأقل (لا يلزم جولة كاملة — تأكيد الدخول والصفحة الرئيسية).

## G) خطة التراجع — Rollback

- [ ] **أندرويد**: نسخة الـ APK السابقة (`versionCode` الأدنى) محفوظة وجاهزة
  لإعادة التوزيع؛ التراجع يستلزم إزالة النسخة الأحدث أولاً إن اختلف مفتاح
  التوقيع، وتظل جلسات student-web سليمة (التراجع لا يمس الخادم).
- [ ] **الويب**: Vercel rollback فوري إلى النشر السابق من لوحة Vercel
  (يسجّل هنا نشر ما قبل الإصدار: `________`).
- [ ] **الخادم**: آخر نشر Render سليم معروف (`________`) + نقطة استعادة
  Neon قبل أي هجرة.

## H) غير الأهداف المعلنة — Explicit non-goals

- [ ] **لا وعد حماية مطلقة**: لا DRM في هذا البرنامج ولا وعد مطلق ضد
  التصوير/التسجيل/الروت — الحدود الصادقة مفصّلة في
  `docs/security/PROTECTION-LIMITS.md`، وهي مرجع أي نص تسويقي أو دعم فني.
- [ ] لا نشر Google Play في RC1 (التوزيع الجانبي فقط)؛ لا Play Integrity
  (لا يزال stub)؛ لا مفاتيح أو أسرار في المستودع إطلاقاً.
