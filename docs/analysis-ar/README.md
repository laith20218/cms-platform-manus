## د. المنهج والتحفظات

- **قراءة فقط**: لم تُعدَّل أي شيفرة، ولم تُجرَ أي عمليات commit أو push، ولم تُشغَّل اختبارات تغيّر الحالة. جرى الاستنساخ بصورة مجهولة الهوية (المستودع عام).
- جميع الأعداد (أسطر الشيفرة، والاختبارات، ونقاط النهاية، والجداول، والمفاتيح الأجنبية، والترحيلات) **معدودة آلياً** من شجرة العمل، لا مقدَّرة تقديراً.
- حالات التشغيل الحية (زمن التشغيل، وزمن الإقلاع البارد، والمحتوى الحالي لقاعدة البيانات، وأسعار المزودين) لم تُفحص، وعُلِّمت بـ UNVERIFIED حيث يلزم.
- وثائق حالة المستودع نفسها تتعارض في مواضع (README مرحلة التصميم مقابل EXECUTION_STATUS الحالية)؛ وعند التعارض يعتمد هذا التحليل **الشيفرة وتاريخ git** مرجعاً للحقيقة ويُنبّه على الانحراف (tech/01 §7.4، وtech/09 §2.3-7).
