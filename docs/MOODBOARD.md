## 1. الإحساس العام

### 1.1 وصف الإحساس بكلمات

> **"غرفة عمليات هادئة فجراً، حيث كل أداة في مكانها، الإضاءة تركّز على المهم، الألوان مريحة للعين، والثقة تملأ المكان."**

الكلمات المفتاحية للإحساس:
- **احترافي** (Professional)
- **هادئ** (Calm)
- **موثوق** (Trustworthy)
- **دقيق** (Precise)
- **حديث** (Modern)
- **شفاف** (Translucent)
- **آمن** (Secure)
- **منظّم** (Organized)
- **طبي** (Medical)
- **واضح** (Clear)

### 1.2 الاستعارة الحسية

تخيّل:
- ✨ **نظرة**: غرفة مكتبية حديثة، زجاج opaque، ألوان هادئة، إضاءة LED ناعمة.
- 👂 **صوت**: همسة خافتة، نقرة لوحة مفاتيح هادئة، صوت نجاح ناعم.
- ✋ **لمس**: سطح زجاجي ناعم بارد، حواف مدوّرة، أزرار بإحساس clickable.
- 👃 **رائحة**: هواء منعش، معقم طبي خفيف، ورق新书 جديد.
- 👅 **طعم**: قهوة سادة دافئة، تركيز هادئ.

## 2. أسلوب التصميم

### 2.1 النمط الأساسي

**Glassmorphism + Medical Precision + Modern Minimal**

مزيج محسّن من:
- **Glassmorphism** (2020+): أسطح شفافة، blur ناعم، طبقات بصرية.
- **Medical UI** (خاص): دقّة طبية، رموز صحية، ألوان مستشفى راقية.
- **Modern Minimal** (2015+): مساحات بيضاء، تركيز على المحتوى، بساطة.

### 2.2 الخصائص المميزة

| الخاصية | الوصف |
|---------|------|
| **الشفافية** | أسطح شفافة بنسبة 60-85% مع blur 12-24px |
| **الحواف** | مدوّرة (10px - 36px) |
| **الطبقات** | 3 طبقات: خلفية، سطح، تراكب |
| **الظلال** | ناعمة، متعددة المستويات، لون أزرق خفيف |
| **التباين** | متوسط (ليس حاداً، وليس ضعيفاً) |
| **الكثافة** | متوسطة، مساحات بيضاء كافية |
| **الزخرفة** | وظيفية فقط، لا زخرفة بلا هدف |

### 2.3 الالتزام بالمرجع

المرجع الأساسي هو ملف `بنك الرثوية.html` الذي يستخدم:
- `backdrop-filter: blur(20px)` للأسطح الزجاجية
- `rgba(255,255,255,.65)` للأسطح الشفافة
- `linear-gradient(135deg, #1976D2, #00BCD4)` للتدرجات
- `border-radius: 14px-36px` للحواف
- `box-shadow: 0 8px 32px rgba(25,118,210,.10)` للظلال

## 4. الإضاءة

### 4.1 فلسفة الإضاءة

> **"إضاءة ناعمة، موزّعة بانتظام، تركّز الانتباه دون إجهاد العين."**

### 4.2 خصائص الإضاءة

#### الوضع الفاتح (Light Mode)
- **الخلفية الأساسية**: `#EEF6FF` (أزرق فاتح جداً).
- **الأسطح**: `#FFFFFF` (أبيض نقي) أو `rgba(255,255,255,.65)` (زجاجي).
- **الظلال**: ناعمة، متعددة الطبقات، لون `rgba(25,118,210,.10)`.
- **التباين**: متوسط، يركّز على المحتوى.
- **الإضاءة المحيطية**: خفيفة، لا تشتت.

#### الوضع الداكن (Dark Mode)
- **الخلفية الأساسية**: `#0B1220` (كحلي عميق).
- **الأسطح**: `rgba(255,255,255,.06)` أو `#1A2438` (كحلي فاتح).
- **الظلال**: أعمق، لون `rgba(0,0,0,.30)`.
- **التباين**: أعلى من الوضع الفاتح.
- **الإضاءة المحيطية**: خافتة، تبرز النصوص.

### 4.3 طبقات الإضاءة (Lighting Layers)

```
طبقة 1: الخلفية العامة (BG Layer)
  ├── أزرق فاتح جداً #EEF6FF
  ├── أو كحلي عميق #0B1220
  └── تدرجات خفيفة (radial-gradient)

طبقة 2: الأسطح (Surface Layer)
  ├── أبيض نقي #FFFFFF (للـ cards الصلبة)
  ├── زجاجي rgba(255,255,255,.65) (للـ glass)
  └── ظل ناعم box-shadow

طبقة 3: التراكبات (Overlay Layer)
  ├── modals: rgba(0,0,0,.40) backdrop
  ├── toasts: rgba(255,255,255,.90)
  └── tooltips: rgba(15,23,42,.95)
```

### 4.4 مصادر الإضاءة الافتراضية

نتخيّل الإضاءة تأتي من:
- **الأعلى**: إضاءة رئيسية موزّعة (50%).
- **الأعلى-اليسار**: إضاءة تركيز (30%).
- **الخلفية**: توهج خفيف (20%).

هذا يخلق عمقاً بصرياً ويبرز الأسطح الزجاجية.

### 4.5 الأضواء التحفيزية (Accent Lights)

| الحدث | الإضاءة | المدة |
|------|---------|------|
| إجابة صحيحة | توهج أخضر `rgba(0,200,83,.20)` | 400ms |
| إجابة خاطئة | توهج أحمر `rgba(255,82,82,.20)` | 400ms |
| Hover على زر | توهج أزرق `rgba(25,118,210,.15)` | 200ms |
| Focus على حقل | توهج سماوي `rgba(0,188,212,.25)` | 200ms |
| نجاح اختبار | توهج أخضر كامل الشاشة | 1s |
| خطأ حرج | توهج أحمر كامل الشاشة | 800ms |

## 5. الخامات

### 5.1 فلسفة الخامات

> **"زجاج، بلور، حرير. لا خشب، لا معدن، لا ورق."**

### 5.2 الخامات المعتمدة

#### M1: الزجاج المضبّب (Frosted Glass)
- **الاستخدام**: البطاقات، الحوارات، الـ navbar.
- **CSS**: `backdrop-filter: blur(20px); background: rgba(255,255,255,.65);`
- **الإحساس**: خصوصية، حماية، حداثة.

#### M2: البلور الشفاف (Crystal Clear)
- **الاستخدام**: الأيقونات الرئيسية، الشعار، badges.
- **CSS**: `background: linear-gradient(135deg, #1976D2, #00BCD4); opacity: .9;`
- **الإحساس**: نقاء، دقّة، قيمة.

#### M3: الحرير الناعم (Silk Smooth)
- **الاستخدام**: الخلفيات، الانتقالات.
- **CSS**: `background: linear-gradient(180deg, #F8FBFF, #EEF6FF);`
- **الإحساس**: هدوء، انسيابية، راحة.

#### M4: المعدن المصقول (Polished Metal) — للـ Accents
- **الاستخدام**: الأزرار الرئيسية، الـ active states.
- **CSS**: `background: linear-gradient(180deg, #42A5F5, #1976D2); box-shadow: 0 4px 12px rgba(25,118,210,.30);`
- **الإحساس**: صلابة، موثوقية، احتراف.

#### M5: الورق الطبي (Medical Paper) — للـ Reader
- **الاستخدام**: قارئ PDF، الأسئلة.
- **CSS**: `background: #FFFEF7;` (أبيض دافئ جداً)
- **الإحساس**: قراءة مريحة، تركيز.

### 5.3 الخامات المرفوضة

| ❌ مرفوض | السبب |
|----------|------|
| خشب | لا يناسب الطابع التقني الطبي |
| معدن خام | يوحي بالبرودة الصناعية |
| ورق كرتوني | يوحي بالرخص |
| جلد | لا يناسب الهوية الطبية |
| بلاستيك | يوحي بالرخيص |
| اسمنت | ثقيل بصرياً، لا يناسب التعليم |

### 6.3 مكتبة الأيقونات المعتمدة

**المكتبة الأساسية**: [Lucide React](https://lucide.dev/)
- **السبب**: 
  - مجانية بالكامل (ISC License).
  - أكثر من 1000 أيقونة.
  - متوافقة مع React 19.
  - تدعم RTL.
  - نمط موحّد ومتناسق.

**المكتبة الثانوية**: [Tabler Icons](https://tabler-icons.io/)
- **السبب**: مكتبة احتياطية، بعض الأيقونات الطبية المتخصصة.

### 6.4 الأيقونات الطبية المخصصة

بعض الأيقونات الطبية غير موجودة في Lucide، نصممها خصيصاً:

| الأيقونة | الاستخدام | الوصف |
|----------|----------|------|
| درع طبي | الشعار، الحماية | درع بداخله صليب طبي |
| نبضة ECG | الإحصائيات الصحية | خط ECG مميز |
| سماعة طبيب | الاستماع | سماعة كلاسيكية |
| محقن | الحقن، اللقاحات | محقن بزاوية 45° |
| جمجمة | التشريح | جمجمة جانبية |
| قلب | القلب، الدورة | قلب تشريحي بسيط |
| رئة | التنفس | رئتان متماثلتان |
| دماغ | الأعصاب | دماغ جانبي |

### 6.5 قواعد استخدام الأيقونات

- ✅ **استخدم** أيقونة + نص دائماً في القوائم والأزرار الرئيسية.
- ✅ **استخدم** أيقونة فقط في الأماكن الضيقة (icon buttons).
- ✅ **استخدم** حجم 16px داخل النص، 20px بجانب النص، 24px في الأزرار، 32px في الـ headers.
- ❌ **لا تخلط** مكتبات أيقونات مختلفة في نفس الصفحة.
- ❌ **لا تستخدم** أيقونات emoji.
- ❌ **لا تستخدم** أيقونات PNG (vector فقط).
- ❌ **لا تستخدم** أيقونات ملونة (monochrome فقط، يرث اللون).

## 7. أسلوب الرسوم

### 7.1 فلسفة الرسوم

> **"رسوم وظيفية، هندسية، بألوان الهوية. لا كرتون، لا ثلاثية الأبعاد مفرطة."**

### 7.2 الأنواع المعتمدة

#### T1: الرسوم الهندسية المسطّحة (Geometric Flat)

## 8. الحركة

### 8.1 فلسفة الحركة

> **"حركة ناعمة، هادفة، سريعة بما يكفي بعدم الإبطاء، بطيئة بما يكفي بعدم الإزعاج."**

### 8.2 المبادئ السبعة للحركة

#### MP1: الطبيعية (Natural)
- استخدام `cubic-bezier(.4, 0, .2, 1)` (Material standard).
- لا حركة خطية (linear) للحركات العضوية.
- الحركات الخطية فقط للأشرطة والمؤقتات.

#### MP2: السرعة المناسبة (Appropriate Speed)
| النوع | المدة |
|------|------|
| Hover | 150-200ms |
| Click feedback | 100ms |
| Page transition | 300-400ms |
| Modal open | 250-300ms |
| Toast appearance | 200ms |
| Toast disappearance | 150ms |
| Loading spinner | 1s loop |
| Progress bar | 300ms per step |
| Stagger (list items) | 50ms between items |

#### MP3: الهدف (Purposeful)
- كل حركة لها سبب: إظهار، إخفاء، تغيير حالة، توجيه انتباه.
- لا حركة "لأنها تبدو جميلة".
- لا حركة بدون قيمة وظيفية.

#### MP4: التدرّج (Staggered)
- عند تحميل قائمة، تظهر العناصر بشكل متدرّج (50ms بين كل عنصر).
- يعطي إحساس "تدفّق" دون تأخير ملحوظ.

#### MP5: الاستجابة الفورية (Immediate Feedback)
- عند النقر، رد فعل بصري خلال 100ms.
- لا انتظار للـ API لإعطاء feedback أولي.
- يتم تحديث الحالة لاحقاً عند وصول الرد.

#### MP6: الاحترام (Respectful)
- احترام `prefers-reduced-motion`.
- إيقاف الحركات للمستخدمين الذين يفضلون ذلك.
- لا حركات لا يمكن إيقافها.

#### MP7: الأداء (Performance)
- استخدام `transform` و `opacity` فقط (GPU-accelerated).
- تجنّب تحريك `width, height, top, left`.
- استخدام `will-change` بحذر.

### 8.3 أنواع الحركة

#### الحركات الميكروية (Microinteractions)
- **Hover on button**: scale(1.02) + box-shadow، 150ms.
- **Click on button**: scale(0.98)، 100ms.
- **Focus on input**: border-color transition + glow، 200ms.
- **Hover on card**: translateY(-2px) + shadow، 200ms.
- **Click on icon**: rotate(15deg)، 150ms.

#### الحركات الانتقالية (Transitions)
- **Page transition**: fade + slide، 300ms.
- **Tab switch**: slide horizontal، 250ms.
- **Modal open**: scale + fade، 250ms.
- **Drawer open**: slide from edge، 300ms.
- **Toast**: slide from top + fade، 200ms.

#### الحركات الاحتفالية (Celebration)
- **Correct answer**: pulse green + scale icon، 400ms.
- **Achievement unlocked**: badge scale + confetti، 600ms.
- **Streak milestone**: flame pulse + shake، 500ms.
- **Course complete**: full-screen overlay + checkmark draw، 1s.

#### الحركات التحذيرية (Warning)
- **Wrong answer**: shake horizontal + red flash، 400ms.
- **Error toast**: slide from top + red glow، 200ms.
- **Connection lost**: pulse red dot، infinite.
- **Security alert**: full-screen pulse red، 800ms.

### 8.4 مكتبة الحركة المعتمدة

**المكتبة الأساسية**: [Framer Motion](https://www.framer.com/motion/)
- **السبب**: 
  - متكاملة مع React 19.
  - declarative API.
  - تدعم `prefers-reduced-motion`.
  - أداء عالٍ (GPU-accelerated).

**البدائل المدروسة**:
- React Spring — جيدة لكن API معقد.
- GSAP — قوية لكن خارج React ecosystem.

### 8.5 الـ Easing Functions المعتمدة

```css
--ease-in-out: cubic-bezier(.4, 0, .2, 1);
--ease-out: cubic-bezier(0, 0, .2, 1);
--ease-in: cubic-bezier(.4, 0, 1, 1);
--ease-spring: cubic-bezier(.5, 1.5, .5, 1);
--ease-bounce: cubic-bezier(.5, 2, .5, 0);
```

| الاستخدام | الـ Easing |
|----------|-----------|
| Page transitions | ease-out |
| Hover effects | ease-in-out |
| Modal open | ease-out |
| Modal close | ease-in |
| Celebration | ease-spring |
| Error shake | ease-bounce |

## 10. الإلهام الطباعي

### 10.1 الخط العربي: Cairo

**لماذا Cairo؟**
- حديث (صدر 2018).
- يدعم 9 أوزان (200-900).
- واضح على الشاشات الصغيرة.
- مجاني (Google Fonts).
- يدعم الأرقام العربية والإنجليزية.
- يدعم RTL.

**أوزان Cairo المعتمدة**:
| الوزن | الاستخدام |
|------|----------|

| 500 (Medium) | التأكيد، الأزرار |
| 600 (SemiBold) | العناوين الفرعية |

### 10.2 الخط الإنجليزي: Inter

**لماذا Inter؟**
- صمم خصيصاً للشاشات.
- واضح حتى 11px.
- متغير (variable font) — أداء أفضل.
- يدعم الأرقام tabular.

## 11. المراجع المرفوضة

### 11.1 ما لا نريد تقليده

| ❌ مرفوض | السبب |
|----------|------|
| تصميم ووردبريس | قديم، فوضوي، غير احترافي |
| Material Design 3 (كما هو) | شائع جداً، غير مميّز |
| Bootstrap templates | عام، يبدو "جاهزاً" |
| Tailwind UI (نسخ مباشر) | يبدو "templated" |
| تصميم Webflow القديم | كلاسيكي، غير عصري |
| Apple Human Interface (كما هو) | جميل لكن غير طبي |
| Microsoft Fluent | مؤسسي بارد، غير دافئ |

### 11.2 ما يجب تجنّبه بصرياً

- ❌ **Stock photos لأشخاص**: عامة، غير أصيلة.
- ❌ **أيقونات emoji**: غير احترافية.
- ❌ **PNG icons**: ضعيفة الجودة، غير قابلة للتوسع.
- ❌ **Background patterns مزدحمة**: تشتت الانتباه.
- ❌ **Gradients فاقعة جداً**: تؤذي العين.
- ❌ **ظلال سوداء قوية**: تبدو قديمة.
- ❌ **حواف حادة 0px**: تبدو خطرة بصرياً (للأزرار الكبيرة).
- ❌ **تدرجات نصية (gradient text)**: صعبة القراءة.
- ❌ **Glass effect على نص**: يقلل التباين.
- ❌ **ألوان متنافرة**: تؤذي العين.
