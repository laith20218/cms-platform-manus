# فحص التدخين RC1 — تطبيق الطالب لأندرويد / RC1 Smoke Test

> **المدة:** ~10 دقائق على هاتف حقيقي واحد (Android 8.0 / API 26 أو أحدث).
> **الغرض:** التحقق قبل التوزيع أن حزمة الـ APK تعمل من البداية إلى النهاية:
> تثبيت، دخول، «تذكّرني»، فتح محتوى مكتبة، لوحة «وضع بدون إنترنت».
> **قبل البدء:** سجّل SHA الحزمة و`versionName`/`versionCode` من مخرجات
> `scripts/android-assemble-student-apk.sh`، وتأكد أن الروابط المدمجة هي روابط
> الإنتاج الحقيقية (HTTPS)، وأن `student-web` و`API` يعملان.

## الخطوات — Steps

- [ ] **1) تثبيت الحزمة (Install)**: انقل ملف APK إلى الهاتف وثبّته
  (`adb install -r app/build/outputs/apk/<type>/app-<type>.apk` أو تحميل جانبي —
  دليل التثبيت: `docs/android-student-apk-guide.md` §7). يظهر التطبيق باسم «CMS».
- [ ] **2) أول فتح (First open)**: افتح التطبيق مع اتصال إنترنت — تُفتح واجهة
  الطالب ويظهر تسجيل الدخول (لا رسالة خطأ، لا شاشة بيضاء).
- [ ] **3) دخول بدون «تذكّرني» (Tab-scoped login)**: سجّل الدخول **بدون** تحديد
  «تذكّرني». اقفل التطبيق كلياً (من قائمة التطبيقات الجارية) ثم أعد فتحه —
  **يجب أن يُطلب تسجيل الدخول من جديد** (الجلسة ماتت مع التبويب — هذا هو
  السلوك الصحيح، ليس خللاً).
- [ ] **4) دخول مع «تذكّرني» (Remember-me)**: سجّل الدخول **مع** تحديد «تذكّرني».
  انتظر حتى تفتح لوحة الطالب، ثم اقفل التطبيق كلياً وأعد فتحه —
  **يجب أن تُستأنف الجلسة دون إعادة تسجيل دخول** (داخل الهيكل الأصلي تُخزَّن
  الرموز مُقفلة بملء AndroidKeyStore — إغلاق debt D-JS-AUTH).
- [ ] **5) فتح ملف مكتبة (Library content)**: من «دراستي» افتح ملفاً واحداً من
  المكتبة (فيديو أو PDF) — يعمل التشغيل/العرض بشكل طبيعي.
- [ ] **6) لوحة «وضع بدون إنترنت» (Offline panel)**: افتح فهرس «وضع بدون إنترنت»
  (المحتوى المحفوظ) — يظهر عدّاد المساحة/الحصة (5 GiB) بشكل صحيح ولو فارغاً.
- [ ] **7) تنزيل ثم الطيران (Offline round-trip)**: احفظ ملفاً واحداً للتخزين دون
  اتصال، فعّل **وضع الطيران**، ثم افتح الملف المحفوظ — يعمل. محتوى YouTube
  يظهر ملاحظة الصدق «غير قابل للحفظ دون اتصال» (سلوك مقصود).
- [ ] **8) تسجيل الخروج (Logout)**: سجّل الخروج — تعود شاشة الدخول، ويُمسح
  المحتوى المخزَّن (لا تبقى نسخة قديمة).
- [ ] **9) حزم الأسئلة دون اتصال (إن فُعّلت في هذا البناء فقط)**: إن بُنيت
  الحزمة مع `OFFLINE_TRUSTED_CLIENT_IMPLEMENTED=true` اختبر تنزيل حزمة أسئلة
  وفتحها دون اتصال. **البناء الافتراضي: الحزم متوقفة (fail-closed)** ويظهر
  نص «حِزم الأسئلة دون اتصال معطّلة في هذا البناء» — عندئذٍ تجاوز هذا البند
  وسجّل «N/A — متوقفة افتراضياً».

## معيار النجاح — Pass criteria

كل البنود 1–8 ✔ (و9 إن كانت الحزم مفعّلة). أي بند فاشل = الحزمة **لا تُوزَّع**؛
سجّل الخطأ مع لقطة شاشة وSHA الحزمة.
