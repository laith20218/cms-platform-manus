# آلة حالات جلسة الاختبار

| الحالة | الدخول | العمليات المسموحة | الأثر |
|---|---|---|---|
| `InProgress` | بدء ناجح بعد فحص النشر والاستحقاق والإتاحة والحد | حفظ إجابة، تحديث الموضع، استئناف، تسليم، إلغاء قبل أول إجابة | لا تُعد محاولة مكتملة بعد |
| `Completed` | تسليم خادمي ناجح قبل انتهاء الوقت | قراءة النتيجة والمراجعة وفق السياسات | تُحتسب مرة واحدة |
| `TimedOut` | وصول طلب بعد `ExpiresAt` أو انتهاء الوقت أثناء التسليم | قراءة النتيجة والمراجعة وفق السياسات | تُحتسب مرة واحدة؛ الاسم التاريخي `Expired` |
| `Cancelled` | إلغاء جلسة بلا إجابة | القراءة التشخيصية فقط | غير محتسبة؛ الاسم التاريخي `Abandoned` |

تُرفض أي محاولة تعديل أو تسليم لجلسة نهائية. التسليم المتكرر لا يعيد التصحيح ولا يكرر الإحصاءات، بل يعيد النتيجة المؤرشفة. الاستئناف لا يعيد بناء الأسئلة من البنك، وإنما يقرأ `ExamSessionQuestion` والخيارات والإجابة المحفوظة من اللقطة.

الانتقال الزمني يتم داخل الخادم عند كل عملية حساسة. إذا اكتشف الخادم انتهاء الوقت فإنه يثبت `TimedOutAt` و`CompletedAt` ويحسب النتيجة من الإجابات الموجودة، ثم يسجل الإحصاءات إذا لم تكن `AnalyticsRecordedAt` مثبتة.
