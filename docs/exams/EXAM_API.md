# عقد API للاختبارات

## الطالب

| الطريقة | المسار | الغرض |
|---|---|---|
| `GET` | `/api/v1/exams?subjectId={subjectId}` | قائمة الاختبارات المنشورة والمتاحة للمادة |
| `GET` | `/api/v1/exams/{examId}` | تفاصيل آمنة لا تكشف الإجابات الصحيحة |
| `POST` | `/api/v1/exams/{examId}/start` | بدء أو استئناف الجلسة، مع `Idempotency-Key` |
| `GET` | `/api/v1/exams/sessions/{sessionId}` | قراءة الجلسة واللقطة والإجابات المحفوظة |
| `PUT` | `/api/v1/exams/sessions/{sessionId}/questions/{questionId}/answer` | حفظ إجابة أو موضع السؤال؛ المسح صريح |
| `POST` | `/api/v1/exams/sessions/{sessionId}/submit` | تسليم وتصحيح خادمي idempotent |
| `POST` | `/api/v1/exams/sessions/{sessionId}/cancel` | إلغاء جلسة بلا إجابات فقط |
| `GET` | `/api/v1/exams/sessions/{sessionId}/results` | النتيجة وفق `ShowResultsImmediately` والسياسات |
| `GET` | `/api/v1/exams/sessions/{sessionId}/review` | المراجعة وفق `AllowReview` وحقول الإفصاح المستقلة |

كل مسار طالب محمي بالمصادقة وترويسة الاستحقاق الأكاديمي عند الحاجة. جسم الإجابة لا يحدد `score` أو `passed` أو الحالة النهائية. الاستجابة تعرض `expiresAt` الخادمي، ولا يستخدم العميل عداداً محلياً كمصدر قرار.

## الإدارة

مسارات `/api/v1/admin/exams` مخصصة للإدارة وتشمل القائمة والتفاصيل والإنشاء والتعديل وإدارة تركيب الأسئلة وإعادة الترتيب والنشر والأرشفة ونتائج الطلاب. تطبق المسارات صلاحية مورد الاختبارات، ثم تتحقق من نطاق المادة. مسار اختيار الأسئلة يعرض المنشور والواقع ضمن المادة والنطاق فقط، وتتحقق عملية النشر من تركيب صالح.

## أخطاء متوقعة

`401` تعني غياب المصادقة أو الاستحقاق، و`403` تعني رفض الاستحقاق أو الصلاحية أو الإتاحة، و`404` يستخدم عند عدم ملكية جلسة الطالب لتقليل تسريب وجودها، و`409` لتعارض الحالة أو انتهاء الجلسة أثناء عملية كتابة، و`422` لطلب لا يطابق سؤال اللقطة أو صيغة الإجابة.
