# مصفوفة الوصول لوحدات إدارة CMS

| الوحدة | `super_admin` | `university_admin` | `year_admin` | `subject_admin` |
|---|---|---|---|---|
| المدراء، الأدوار، إعدادات النظام وسجل التدقيق | كامل | لا وصول | لا وصول | لا وصول |
| الجامعات | إنشاء وتعديل وتعطيل | عرض نطاقه فقط | عرض نطاقه فقط | عرض نطاقه فقط |
| الكليات والسنوات والفصول | كامل | إنشاء وتعديل ضمن جامعته | عرض ضمن سنته | عرض ضمن مادته |
| المواد | كامل | إنشاء وتعديل ضمن جامعته | إنشاء وتعديل ضمن سنته | عرض مادته فقط |
| المحاضرات والملفات والفيديو والصوت | كامل | ضمن جامعته | ضمن سنته | إنشاء وتعديل ونشر ضمن مادته |
| الأسئلة والاختبارات | كامل | ضمن جامعته | ضمن سنته | إنشاء وتعديل ومراجعة ونشر ضمن مادته |
| الطلاب والجلسات | كامل | عرض وإدارة ضمن جامعته | عرض وإدارة ضمن سنته | لا إدارة حسابات الطلاب |
| الإشعارات | كامل | توجيه ضمن جامعته | توجيه ضمن سنته | توجيه ضمن مادته |
| التقارير والأحداث الأمنية | كامل | تقارير نطاقه التشغيلية فقط عند توفرها | تقارير نطاقه التشغيلية فقط عند توفرها | تقارير محتوى مادته فقط عند توفرها |

> جميع القرارات تُفرض من الخادم عبر صلاحية المورد والفعل أولًا، ثم فحص مسار الكيان الأكاديمي؛ إخفاء عنصر الواجهة لا يُعد تفويضًا.
