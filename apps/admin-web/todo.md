# قائمة توسعة لوحة إدارة CMS

## الهوية والنشر

- [ ] إصلاح ظهور شعار CMS الكامل والرمز المجرد في نشر Vercel والتحقق من ملفات الأصول العامة.
- [ ] توحيد شاشة الدخول ولوحة القيادة مع فلسفة «غرفة القيادة السريرية» المعتمدة.

## وحدات البنية الأكاديمية

- [ ] إدارة الجامعات: إنشاء وتعديل وتعطيل ضمن صلاحية `super_admin` فقط.
- [ ] إدارة الكليات والسنوات والمواد مع فرض علاقتها الهرمية في الخادم.
- [ ] تقييد الجامعة والسنة والمادة تلقائيًا بحسب نطاق `university_admin` و`year_admin` و`subject_admin`.

## وحدات المحتوى

- [ ] إدارة المحاضرات: مسودة ومراجعة ونشر وأرشفة، مع منع المحتوى غير المنشور من API الطالب.
- [ ] رفع وربط ملفات المحاضرات والمراجع والفيديو والتسجيلات الصوتية عبر التخزين الخاص وروابط موقعة.
- [ ] إدارة بنك الأسئلة ومراجعتها ونشرها وربطها بالمادة والمحاضرة.
- [ ] إدارة الاختبارات ونطاقها ووقت إتاحتها ومحاولاتها وحالة نشرها.

## الطلاب والتشغيل

- [ ] إدارة الطلاب والبحث والتصفية والحالات والجلسات وإبطال الجلسات وفق الدور والنطاق.
- [ ] إظهار سجل التدقيق والأحداث الأمنية والتقارير دون إتاحة تعديل سجل التدقيق.
- [ ] إضافة لوحة تشغيل تعرض بيانات حقيقية فقط، دون أرقام أو مراجعات تجريبية.

## التحقق والنشر

- [ ] إضافة اختبارات تفويض وتكامل لكل وحدة وصلاحية نطاقية.
- [ ] رفع التغييرات، تطبيق أي ترحيلات لازمة، والتحقق خارجيًا من الإنتاج.
