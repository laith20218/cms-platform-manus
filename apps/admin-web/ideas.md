# غرفة القيادة السريرية — واجهة إدارة CMS

هذه الواجهة تتبع فلسفة **غرفة القيادة السريرية** المعتمدة: سطح عاجي دافئ، سلطة بصرية كحلية، وإشارات حالة فيروزية محدودة. يستخدم الشريط الجانبي كعمود ملف طبي ثابت، مع تسلسل غير متماثل، وتنفيذ واضح لكل إجراء حساس. الخطوط المعتمدة هي IBM Plex Sans Arabic للنصوص وDM Mono للمعلومات التشغيلية.

> جوهر العلامة: لوحة تشغيل موثوقة لإدارة التعليم الطبي الجامعي، موجهة للمديرين الذين يحتاجون إلى تحكم واضح لا إلى ضوضاء بصرية.
